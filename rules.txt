# Café Website Development Prompt

Build a production-ready, responsive café website using modern web development best practices.

## Branding & Design

* Use the provided logo located at `/images/logo`.
* Extract the exact brown and white colors from the logo and use those HEX values consistently throughout the website.
* The design should feel like a real premium café website—not an AI-generated template.
* Do **not** use glassmorphism, transparency, opacity effects, blurred backgrounds, floating cards, or excessive gradients.
* Keep the UI clean, elegant, modern, and minimal.
* Focus on excellent typography, spacing, and usability.
* Fully responsive across desktop, tablet, and mobile.
* Optimize for accessibility (WCAG where possible), performance, and SEO.
* Use smooth but subtle animations only where they improve UX.

# Branches

The café has **three branches**:

1. Al Basateen
2. Al Mohammadiyah
3. Al Manar

Each branch has:

* Its own menu
* Different available products
* Different pricing if applicable
* Different operating hours (if provided)

---

# Customer Experience

Visitors can browse the website without logging in.

Registration is required before placing an order.

Registration includes:

* Full Name
* Mobile Number
* Phone verification via OTP
* Email Address

Login should support:

* Phone number + OTP
  or
* Email + Password (if implemented)

---

# Branch Selection

When opening the website:

* Request the user's location.
* Automatically select the nearest branch.
* The user can manually switch branches at any time.
* Save the selected branch during the session.

---

# Ordering Flow

The customer should be able to:

1. Select a branch.
2. Browse that branch's menu.
3. View product images.
4. View product details.
5. Add items to cart.
6. Choose:
   * Drive-Thru Pickup
   * Dine-In / In-Branch Pickup
7. Review cart.
8. Enter or confirm their name.
9. Place the order.

There is **no online payment**.

The customer pays at the branch when collecting the order.

---

# Order Radius Restriction

Ordering ahead is only available if the customer is within a **5-minute driving radius** of the selected branch.

If the user is outside that radius:

* Disable ordering.
* Show a friendly message explaining that advance ordering is only available within a 5-minute radius.

Use Google Maps (or another mapping service) to calculate actual travel time rather than straight-line distance.
